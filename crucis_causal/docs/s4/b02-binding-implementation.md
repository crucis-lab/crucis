# B02 exact evidence binding and planning

DLV-08, DLV-09.

[Resolution](../../measurement/resolution.py) materializes only explicitly
supplied, authorized and pinned evidence. Its read budget counts visits
and bytes. A selected reference carries its original package identity,
digest, record identity and selected bytes. An artifact read verifies the
snapshot extent and its digest before applying an allowed selector.

[Planning](../../measurement/planning.py) checks the selected plan,
question, scopes, bindings, source slots, versioned procedure declaration,
implementation and selected preflight premises. Each output can be ready
or held. The plan binds resolved inputs and actual limits to a basis digest.
It performs no evaluator call, write or claim assessment. Procedure
availability at planning does not establish evaluator qualification.

The B02 fixture checks S1 artifact, S2 case and S3 audience records using
their actual codecs. It exercises an output-local hold and a common
prerequisite hold, a changed locator body, mismatched slot and exact
registry rules, immutable outputs and scoped budget enforcement. The
fixtures qualify the bounded preparation path. Evaluator admission,
durable work and scientific procedure gates follow in later bundles.
